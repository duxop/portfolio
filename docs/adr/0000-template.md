## Context

Three sentences. What forced this question? Cite the concrete thing: a requirement ID, a file and line, a measured number, a docs page with its date. If you cannot point at something specific, this may not be a real decision yet.

## Options

### Option 1: name

What this means in practice.

- **Pros:** …
- **Cons:** …
- **Cost to reverse:** …

### Option 2: name

- **Pros:** …
- **Cons:** …
- **Cost to reverse:** …

## Recommendation

Which one, and why, including what the other options are better at, so the trade-off being accepted is explicit. Written by whoever prepared the ADR.

## Decision

What was chosen, in the decider's words. "Went with the recommendation" is a good rationale and more honest than inventing one.

## Consequences

What this forces, enables and forecloses. Include the unpleasant ones; an ADR that lists only benefits is a sales pitch.

## Revisit when

A concrete, observable trigger. Not "periodically", not "if it becomes a problem".
